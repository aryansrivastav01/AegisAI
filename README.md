# 🛡️ AegisAI

> Your AI SOC Analyst

AegisAI is an AI-powered SOC (Security Operations Center) Analyst platform designed to help security professionals analyze logs, investigate incidents, extract Indicators of Compromise (IOCs), map MITRE ATT&CK techniques, and generate incident reports.

## 🚀 Planned Features

- AI Log Analysis
- IOC Extraction
- MITRE ATT&CK Mapping
- Incident Summarization
- Severity Classification
- Security Dashboard
- Report Generation

## 🛠️ Tech Stack

### Frontend
- Next.js
- TypeScript
- TailwindCSS

### Backend
- FastAPI
- PostgreSQL

### AI
